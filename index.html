How It Works

1
Install the loader script (tiny — 4KB). It's the only thing you install in Tampermonkey.
2
Visit arena.ai — the loader downloads the main script from GitHub, caches it, and reloads once.
3
From now on, the main script loads instantly from cache — no delay, no refresh. Catches RSC data before React.
4
When a new version is pushed to GitHub, the loader auto-downloads it and reloads once. Then back to instant loads.

🔄 Auto-Update System

The loader checks version.json on every page load. If the version on GitHub is newer, it downloads the updated script, caches it, and reloads the page once. Normal page loads use the cached version for zero-delay injection. No manual updates needed.
